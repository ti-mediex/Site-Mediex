# COMO EDITAR SEM QUEBRAR:
#
# 1) Um robo obedece a UM UNICO grupo - o mais especifico que casa
#    com o nome dele - e ignora todos os outros, inclusive o
#    "User-agent: *". Por isso os tres grupos abaixo repetem a
#    MESMA lista de regras. Alterou um, altere os tres.
#    Nunca criar um grupo so com "Allow: /": isso apaga todos os
#    Disallow para aquele robo.
#
# 2) A regra "Disallow: /*.txt$" barra os payloads internos do
#    Next.js (um .txt por rota = conteudo duplicado). Todo .txt
#    publico novo precisa de um "Allow:" proprio nos tres grupos,
#    senao nasce bloqueado.
#
# 3) Antes de subir, rode:  python scripts\validate_robots.py
#    Ele checa divergencia entre os grupos, regras sem efeito e uma
#    suite de comportamento. Foi assim que se pegou a falta de um
#    Disallow no grupo do AdsBot.
# ==============================================================

# 1. Regra geral - vale para todo robo nao citado adiante
# --------------------------------------------------------------

# Rotas internas, sem valor de busca.
# /__next e redundante com /*.txt$ hoje; mantido de proposito como
# guarda, caso o Next passe a emitir artefato interno com outra
# extensao.
Disallow: /api/
Disallow: /_next/data/
Disallow: /__next
Disallow: /enviar-orcamento.php
Disallow: /*.txt$

# Os .txt publicos, liberados um a um (ver item 2 no topo)
Allow: /robots.txt
Allow: /llms.txt

# antes, degradava essa avaliacao.
